# 新技能提案模板（v0.10）

> 触发条件（满足任一）：同主题规则 ≥3 条；同类型任务成功 ≥3 次。
> 使用本模板时复制一份填写，提案须经用户确认后方可固化。

## 提案

- **技能名**：skill-<领域>-<核心动作>（不得与现有技能重名）
- **触发场景**：（什么任务应调用此技能，写进 frontmatter description）
- **来源依据**：（哪几条规则 / 哪些成功任务，列出证据）
- **核心流程**：（步骤清单，1-7 条可执行步骤）
- **验证方式**：（用哪类真实任务验证）
- **验证结果**：通过 / 未通过（未通过则不进技能库）

## 固化流程

1. 用户确认提案。
2. 在技能库目录创建 `<技能名>/SKILL.md`，frontmatter 含 name/description。
3. 用一次真实任务验证。
4. 通过 → 启用并记录到 `技能统计` 记忆；失败 → 修复后重试，最多 2 次，仍失败则放弃并记录原因。

## 约束

- 禁止修改 EVO 自身（L0/H9 核心自锁，版本升级仅由用户授权）。
- 新技能只含已验证步骤，未经验证的标为 `[实验]`。
- 固化后向 `data/journal.md` 追加一行变更记录（H14 纯审计）。
