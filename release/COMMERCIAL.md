# 商业授权

本项目采用 **AGPL-3.0-or-later** 与**商业授权**双轨制。

---

## 双轨划分

| 范围 | 许可 | 说明 |
|---|---|---|
| **代码**（`bin/` `lib/` `data/cmd/` `refs/` `templates/`） | AGPL-3.0-or-later | 自由使用、修改、分发 |
| **规范**（`SKILL.md` `CHANGELOG.md`） | AGPL-3.0-or-later | 同上 |
| **本项目积累的评测集**（含真实账本标题的 `search-evalset*.tsv`） | 商业授权 | 不随仓库发布 |
| **商业包**（判据层 + 门禁阈值配置 + 更新服务） | 商业授权 | 需申请 |

注意：公开仓库中**包含**对抗用例定义（`data/adversarial-tests.tsv`）。它是可信度证明，刻意公开。
**不包含**评测集实体、真实账本、门禁阈值调优配置。

---

## AGPL 下你可以

- ✅ 个人/团队内部使用、修改
- ✅ 分发修改后的版本（须保留 AGPL 与版权声明）
- ✅ 用于商业项目（自用，不对外提供服务）
- ✅ 在 air-gapped / 离线 / 内网环境部署（这正是本项目的主场）

## AGPL 下你需要注意

- ⚠️ 若把衍生作品**作为网络服务**提供给第三方（SaaS），须以 AGPL 开放你的完整源代码
- ⚠️ 不得移除版权声明与许可声明
- ⚠️ 不得用本项目名称/作者名义为衍生品背书

---

## 什么时候需要商业授权

| 场景 | 是否需要 |
|---|---|
| 个人使用 | 否 |
| 公司内部使用（不对外服务） | 否 |
| 集成进闭源产品对外销售 | **是** |
| 做成 SaaS / 托管服务 | **是**（或按 AGPL 开源全部代码） |
| 需要评测集与判据层 | **是** |
| 需要 SLA / 技术支持 / 定制门禁 | **是** |

## 联系方式

公开仓库 Issues 开一个 `commercial` 标签的 issue，或邮件联系维护者。

**不要在公开 issue 里贴生产配置、账本内容、内部路径。**

---

## 为什么这样设计

EVO 的价值不在代码。2-gram 检索约 100 行，谁都能写；门禁框架也是常规工程。

真正值钱的是**判据的积累**：

- 那 32 条对抗用例是踩坑踩出来的，不是设计出来的
- 那 20 题真实问法集是从实际失手反推的
- 每一道门禁背后都对应一次真实事故

MIT 会让这些积累被白嫖且不回馈。AGPL 保留了"要商用就谈"的可能，同时对个人与内网使用者完全免费 —— **这正是本项目想服务的对象。**
