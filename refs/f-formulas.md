**命令化三条（写死，禁止心算/试错循环）：**

1. **时间戳**：一律 `date -u` 实测 + 换算北京（UTC+8），禁止凭印象写时间。
2. **打包字节收敛**：跑 `sh bin/evo pack`（v0.15 脚本固化）；无 shell 时按三轮流程：先打包拿 N1 → pack 行等长回填 → 重打包；最多 3 轮，不收敛则挂账记「压缩漂移」并停止迭代。
3. **journal 追加**：一律 `sh bin/evo journal-add <op> <对象> <内容> [标记]`（v0.15.1 唯一入口，路径写死+北京时间戳+op/破表拦截）；无 shell 降级才 `echo '...' >> data/journal.md`（printf 会丢换行）。

**命令固化脚本（v0.15，第四层拿回——命令本体不再现场拼）：** `data/cmd/` 六件：`enum_merge.sh`（H21 合并出数+对账提示+中间文件清理）/ `verify.sh`（H5 diff 判定+清理）/ `pack.sh`（打包收敛）/ `journal-lint.sh`（格式三查+H1 计数+查5 游离账本检查）/ `rotate-journal.sh`（截断轮转）/ `journal-add.sh`（v0.15.1 落账唯一入口）。脚本受 H9 保护，SKILL.md 只引用脚本名，执行时跑脚本不拼命令。
